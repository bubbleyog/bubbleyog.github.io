# 神经网络基础：从感知机到深度学习

神经网络是深度学习的核心。理解其工作原理，是掌握现代AI技术的基础。

## 感知机：一切的开始

感知机是最简单的神经网络单元，由Rosenblatt于1958年提出。

```
output = activation(Σ(wᵢ · xᵢ) + b)
```

感知机可以学习线性可分的问题，但无法解决XOR问题，这导致了第一次AI寒冬。

## 多层感知机（MLP）

通过堆叠多个层，神经网络可以学习非线性函数：

- **输入层**：接收原始数据
- **隐藏层**：提取特征表示
- **输出层**：产生最终预测

### 激活函数

激活函数引入非线性，使网络能学习复杂模式：

- **ReLU**：f(x) = max(0, x)，计算简单，缓解梯度消失
- **Sigmoid**：将输出压缩到(0,1)，适合概率预测
- **Tanh**：均值为0，收敛更快
- **Softmax**：多分类问题的输出层

## 训练神经网络

### 前向传播

数据从输入层流向输出层，计算预测结果。

### 损失函数

衡量预测与真实值的差距：

- **MSE**：均方误差，用于回归
- **交叉熵**：用于分类
- **KL散度**：衡量分布差异

### 反向传播

根据链式法则计算梯度，从输出层向输入层传播误差，更新权重。

```python
# 梯度下降更新
w = w - learning_rate * gradient
```

## 优化技巧

### 1. 批归一化（Batch Normalization）

对每层的输入进行归一化，加速训练，允许使用更大的学习率。

### 2. Dropout

训练时随机丢弃部分神经元，防止过拟合。

### 3. 学习率调度

- 学习率衰减
- 余弦退火
-  warm-up

### 4. 正则化

- L1正则化：产生稀疏权重
- L2正则化：限制权重大小

## 卷积神经网络（CNN）

专门处理网格数据（图像）的架构：

- **卷积层**：提取局部特征
- **池化层**：降维，增加平移不变性
- **全连接层**：最终分类

经典架构：LeNet → AlexNet → VGG → ResNet → EfficientNet

## 循环神经网络（RNN）

处理序列数据的架构：

- **LSTM**：长短期记忆，解决长程依赖
- **GRU**：门控循环单元，LSTM的简化版
- **Transformer**：注意力机制取代循环，并行计算

## 现代趋势

1. **自监督学习**：利用无标注数据
2. **神经架构搜索**：自动设计网络结构
3. **量化与剪枝**：模型压缩，边缘部署
4. **可解释AI**：理解模型决策过程

神经网络的发展展示了计算能力、数据规模和算法创新结合的力量。理解基础原理，才能在快速变化的领域中保持竞争力。
